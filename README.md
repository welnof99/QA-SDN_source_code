# QA-SDN: reproduction package

Code, data, figures and an executable notebook for the article

> Satria, W. *Simulated Quantum Annealing versus Simulated Annealing for SDN Flow Admission under Matched Compute: A Controlled Study.* Submitted to the International Journal of Intelligent Engineering and Systems (IJIES). [PLACEHOLDER: final citation and DOI once published]

The package reproduces every table and figure in the article's Results (Sections 4.1–4.10) from the released CSV data, and it can regenerate the raw data from the code.

## Reproducing the results

Requirements: Python 3 with the packages in `requirements.txt`.

```bash
pip install -r requirements.txt
```

1. **Reproduce the analysis, tables and figures from the released data (fast, minutes):**
   ```bash
   jupyter nbconvert --to notebook --execute --inplace notebooks/MAS-QA-SDN_article_reproduction.ipynb
   ```
   or open the notebook in Jupyter and run all cells. The notebook reads `data/` and writes `figures/`.

2. **Regenerate figures from the data without the notebook:**
   ```bash
   python code/figures_main.py
   python code/figures_extra.py
   ```
   Set the environment variable `MASQA_ROOT` to the package root if the scripts are run from another directory.

3. **Regenerate the raw data (slow).** The main and scale runs take substantial CPU time. The small-instance rerun takes about 20 minutes. Run:
   ```bash
   python code/exp.py
   python code/small_instances.py
   ```
   The regenerated CSV files should match `data/` for the same seeds. The timing columns will differ with hardware (see `data/README.md`).

Random seeds are fixed in the code. Evaluation seeds (42–71 for the main protocol) are disjoint from tuning seeds (100–114).

## Notes on the data

- `data/README.md` defines every column and file.
- Timing columns are recorded on the machine used for the experiments and are not validated. The article's efficiency claims use annealing work (spin updates), not wall-clock time.
- `code/exp.py` contains a superseded small-instance step (`optimum_small.csv`) that used an earlier demand rule. The article uses `code/small_instances.py` and `data/small_v2_all.csv`. The superseded output is not included in this package.
